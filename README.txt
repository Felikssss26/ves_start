ВЕСЁЛЫЕ СТАРТЫ: результаты и статистика соревнований — приложение (PWA)

УСТАНОВКА
1. Выложите ВСЮ эту папку на GitHub Pages (или другой хостинг с https), структуру папок менять нельзя.
2. Откройте ссылку на телефоне. Android (Chrome): кнопка «Установить» в шапке или меню ⋮ → «Установить приложение».
   iPhone (Safari): «Поделиться» → «На экран Домой».
3. Первый запуск — с интернетом. Дальше работает и без сети.

ПРОТОКОЛЫ ВНУТРИ ПРИЛОЖЕНИЯ
Файлы лежат в папке data, а их список — в файле data/index.json. При каждом запуске программа сама загружает их.
Как добавить или заменить протокол:
  1. На GitHub откройте папку data → Add file → Upload files, загрузите файл Excel (если имя такое же, как у старого, он заменится).
  2. Для нового файла впишите его имя в data/index.json (откройте файл, нажмите значок карандаша, добавьте имя в кавычках через запятую, Commit changes).
  Подойдут: итоговый протокол, стартовый протокол, техническая заявка (.xlsx или .xls).
Через 1–2 минуты после загрузки на GitHub обновление появится у всех при следующем запуске с интернетом.
Внимание: всё, что лежит на GitHub Pages, публично (ФИО, годы рождения, результаты).

ВИД НА ТЕЛЕФОНЕ
По умолчанию на телефоне страница показывается как версия для ПК: всё помещается по ширине, листать вбок не нужно (масштаб можно менять щипком).
Кнопка «Вид: ПК / Вид: телефон» в шапке переключает на обычную мобильную вёрстку.

Если телефон показывает старую версию программы, увеличьте номер V в начале файла sw.js (например, ves-v4).
