ВЕСЁЛЫЕ СТАРТЫ: результаты и статистика соревнований — установка как приложения (PWA)

1. Выложите ВСЮ эту папку на любой хостинг с https (проще всего GitHub Pages, Netlify или Cloudflare Pages).
   Структуру папок (icons, lib) менять нельзя.
2. Откройте ссылку на телефоне.
   Android (Chrome): нажмите «Установить» в шапке программы или меню ⋮ → «Установить приложение».
   iPhone (Safari): «Поделиться» → «На экран Домой».
3. Первый запуск — с интернетом (программа сохраняет себя в память телефона). Дальше работает без сети.
4. Загрузите файлы Excel в самой программе. Они сохраняются только на этом устройстве, кнопка «Очистить» их удаляет.

Обновление программы: замените файлы на хостинге. Если телефон показывает старую версию, увеличьте номер V в начале файла sw.js (например, ves-v2).
