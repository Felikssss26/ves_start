ВЕСЁЛЫЕ СТАРТЫ: результаты и статистика соревнований — приложение (PWA)

УСТАНОВКА
1. Выложите ВСЮ эту папку на GitHub Pages (или другой хостинг с https), структуру папок менять нельзя.
2. Откройте ссылку на телефоне. Android (Chrome): меню ⋮ в приложении → «Установить приложение» (или меню браузера).
   iPhone (Safari): «Поделиться» → «На экран Домой».
3. Первый запуск — с интернетом. Дальше работает и без сети.

КАК УСТРОЕНО
При запуске показывается список соревнований (карточки: название, дата, место). По нажатию на карточку подтягиваются
материалы этого соревнования: итоговый протокол, стартовый протокол, заявка. Кнопка «← Соревнования» возвращает к списку.
Во вкладке «Сравнение» используются итоги всех соревнований из списка.

КАК ДОБАВИТЬ СОРЕВНОВАНИЕ
1. Загрузите файлы Excel в папку data на GitHub (Add file → Upload files).
2. Откройте data/index.json (значок карандаша) и добавьте блок в список, скопировав любой существующий:
   {
    "id": "kubok-2026",                 — короткий уникальный код (латиницей)
    "title": "Название соревнования",   — крупный заголовок карточки
    "short": "Кубок",                   — короткое имя для таблицы «Сравнение»
    "place": "г. Тирасполь",            — место проведения
    "date": "10–11.12.2026",            — дата для показа на карточке
    "start": "2026-12-10",              — дата начала (по ней сортируются карточки, новые сверху)
    "note": "Необязательная пометка",
    "upcoming": true,                   — для предстоящего соревнования (карточка без материалов; список "files" оставьте пустым: [])
    "files": [ {"name": "kubok_itog.xlsx", "kind": "itog"},        — итоговый протокол
               {"name": "kubok_start.xlsx", "kind": "start"},      — стартовый протокол
               {"name": "kubok_zayavka.xls", "kind": "zayavka"} ]  — техническая заявка
   }
   Если всё лежит в одной книге Excel (на разных листах), укажите один файл и перечислите виды материалов:
     "files": [ {"name": "kubok.xlsx", "kinds": ["itog", "start", "zayavka"]} ]
   Блоки разделяются запятой. Подойдут файлы .xlsx и .xls. Лишние листы лучше удалить: читается всё, что есть в файле.
3. Через 1–2 минуты обновление появится у всех при следующем запуске с интернетом.

СВОИ ФАЙЛЫ
Карточка «+ Открыть свои файлы Excel» (или меню ⋮) позволяет загрузить протоколы только на этом устройстве.
Они появятся отдельной карточкой «Загруженные мной файлы» и сохранятся. Удалить: меню ⋮ → «Удалить загруженные файлы».

ВИД НА ТЕЛЕФОНЕ
По умолчанию на телефоне страница показывается как версия для ПК (листать вбок не нужно). Кнопка «Вид» в меню ⋮ переключает на мобильную вёрстку.

Внимание: всё, что лежит на GitHub Pages, публично (ФИО, годы рождения, результаты).
Если телефон показывает старую версию, увеличьте номер V в начале файла sw.js (например, ves-v5).
